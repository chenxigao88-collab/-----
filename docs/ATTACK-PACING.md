# 攻击动作可读性调整

角色普通攻击和两名角色右键连招的动作时长增加约 20%。连招命中、射击时点按相同比例延后，刀光播放同步延长；逐段按右键的缓冲和续接窗口保持原规则。

普通射击动作由 0.16 秒延长至 0.192 秒。连续射击只更新当前动作的瞄准角，不会每枪重置姿势，出枪后的收势帧可以正常显示。普通近战的动作和实际判定共用起手、挥击、恢复时长，攻速增益仍按比例生效。紫鸾普通攻击使用已有绘制素材：巨刃下劈四帧、站立射击两帧，枪械挂点跟随相应手部位置。

普通怪物、精英和 Boss 的起手、伤害生效阶段、恢复阶段增加约 20%。锁定方向的最后阶段同步延长，攻击预告、角色图像和伤害使用相同时间。线棺及 Boss 突进保留移动距离，延长完成时间。防守关的攻击逻辑使用相同怪物节奏。

移动、闪避、子弹速度、枪械连发间隔、蓄力时长、伤害数值和 Q 的 3 秒冷却保持原规则。两段大招保留原有完整演出时间。紫鸾右键挑飞的基本浮空时长同比延长，让放慢后的两次跪射仍能接上浮空目标；落地衔接按实际旋身动作长度计算。

回归覆盖完整武器连招、敌人锁向与突进、浮空接枪、强化与元素、暂停、Q 冷却、防守关与完整章节。浏览器检查绘制素材的各个普通挥刀帧、连续射击收势、六段连招和敌人延后的实际攻击。数值入口：`src/data/attackPacing.ts`。
