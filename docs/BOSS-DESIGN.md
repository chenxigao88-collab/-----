# 灰冠骑士：战斗设计与接入

2026-10-10。沿用第一章「最后一盏归途灯」的守关设计，已有角色图集、炉心房间和剧情均继续使用。本次完善攻击序列、阶段韧性、危险清理和战斗提示。

## 角色与场地

灰冠骑士是守了十二年的最后守门人。黑铁铠甲、断冠、发光炉心、旧红披风和熔刃对应已有32帧图集 `public/art/chapter-boss-v1.png`。在内城守关之后进入炉心，入场对话结束后开战；击败后播放倒地与最后对话，取走战利箱，在炉心按 E 进入结局。

## 三阶段

| 阶段 | 生命条件 | 韧性 | 招式与压力 |
|---|---|---|---|
| 最后的守门人 | 高于65% | 150 | 单次横斩、突进下砸交替 |
| 裂铠 | 30%至65% | 180 | 横斩后回身再斩；一次召唤两只寄生体；每7秒一条预警火裂 |
| 炉心燃尽 | 不高于30% | 210 | 保留第二阶段招式，每三套攻击加入一次三段斩 |

0.8基础生命12000、护甲18，独立于普通怪物深度倍率；见 [BALANCE-0.8.md](BALANCE-0.8.md)。首刀前摇1秒，回身刀0.85秒，每刀最后0.22秒固定方向。横斩范围140像素；下砸突进160像素，预警覆盖移动通道和落点。下砸伤害为基础的120%，三段斩每刀85%；刀间恢复0.65秒，整套结束恢复1.65秒再休息0.85秒。

一套攻击的段数在起手时确定。血量跨阶段不会向当前已预告的招式临时追加一刀，新招式从下一套开始。火裂计时从第二阶段开始，预警0.95秒后生效，敌方时停和暂停均停止计时。

## 破韧与公平性

子弹削韧3、重击6、枪斗身体段12、终结枪8、大招每段14、元素反应14、精准闪避18。同一直接攻击 ID 不重复削韧。阶段升级增加韧性上限与对应增量，保留此前已削掉的韧性。

破韧取消正在进行的刀判定、连斩与突进，跪地2.5秒，期间受到伤害增加20%。跨阶段不打断跪地；起身后恢复当前阶段全部韧性，并给予1秒出手缓冲。普通攻击仍能造成生命伤害和元素反应，但不能将 Boss 无限硬直、击飞或被大招聚拢拖动。

血条显示65%与30%阶段刻度，韧性条显示数值，破韧时显示剩余时间和易伤收益。击败后取消待出生敌人、清理小怪、火裂、弹丸、近战判定及持续攻击效果；死亡当帧不再执行阶段切换、召唤或出招。

## Q 手动换武器

Q 成功切换后进入3秒冷却，短暂换持动作锁仍为0.16秒。冷却只限制 Q，不阻止普通射击、闪避、右键连招或大招。右键终结与大招中的自动换持不读取、启动或刷新 Q 冷却。失败的 Q 不消耗冷却。

武器栏显示 Q 倒计时；暂停停止计时，过门与营地存档保留剩余时间。旧存档缺少该字段时按0处理。重新启程创建新冒险，冷却归零。

## 验证

专门回归见 `tests/boss.test.ts` 和 `tests/manual-swap.test.ts`，覆盖阶段阈值、连斩段数、锁向、火裂与召唤、破韧起身、同帧死亡，以及 Q 对普通攻击、两角色连招、大招、暂停和存档的影响。整章流程沿用两角色真实攻击无敌夹具；真人生存难度仍需要试玩确认。
