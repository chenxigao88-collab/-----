# 紫夜终幕

紫鸢专属大招。战斗中满100能量后按 R，瞄准前方扇区，最多锁定5名240像素内、无遮挡的敌人。无目标不扣能量；其他角色、暂停、过门、闪避期间不能释放。允许接在普通连招中，取消原连招后进入大招。

## 能量

有效直接命中每次+2，同一攻击最多奖励2次；普通连招末枪命中额外+8，每个序列一次；元素反应+6；时停闪避+12；击杀+4。0.11起上限200，分两层，每层100；R消耗100并保留剩余能量，Shift+R消耗200发动[紫鸾·断月](VIOLET-MOON-ULTIMATE.md)。复制、持续伤害和大招自身攻击不积攒能量，大招期间的反应和击杀也不回充。能量跨房间保留，新一局和更换角色清空。

## 演出

共4.8秒，敌方时钟暂停，角色无敌，关闭移动、闪避、射击、换枪和交互。暂停仍有效。镜头最高放大1.6倍，根据目标分布降低放大倍率。近距离目标被回旋缓慢聚拢，不穿过柱子。结束后立刻恢复玩家操作，目标有短暂硬直，避免恢复瞬间攻击。

0–0.65起势；0.65–1.25巨刃下劈挑起；1.25–1.85回旋聚拢；1.85–2.45第一枪；2.45–2.95第二枪；2.95–3.6回身换枪第三枪；3.6–4.3大剑回旋终击；4.3–4.8收势。

六段攻击发动时点为1.04、1.54、2.15、2.72、3.22、4.08秒。前两刀基础伤害12、8；接下来的三个武器段分别使用释放时当前武器两次、副武器一次，每枚弹丸或一次挥斩为对应武器基础伤害×0.4，附着对应元素。散弹发射六枚独立散射弹丸，伤害只计算实际命中的弹丸。第3个武器段自动换持，结束后保留副武器。

武器段统一调用普通攻击的真实弹丸／近战发射逻辑，保留原本的速度、射程、数量、散布、穿透、反弹及冰晶减速、火球溅射、跳电等原生效果。每次自动瞄准存活锁定目标中最近的一名，按真实弹丸碰撞结算伤害，锁定不提供必中或穿墙。使用玩家时钟飞行，不会因敌方时钟暂停而停滞。弹丸可以自然穿透／溅射其他实际碰到的敌人，不逐个锁定目标重复发射整组弹丸。外观和枪口使用装备武器；取消枪口至目标的光线。射击姿势中的固定枪身／枪口火焰由运行时分层枪械替代。

缄锋不替换成副枪，对应段播放巨刃回旋动作并生成真实近战判定：72像素范围、1.92弧度扇区及原有起手／判定／收势。超出范围或隔着障碍物可打空，没有远程伤害补偿；普通连招也遵循同一规则。大招固有的开场两刀、聚拢与末刀演出保持原设计。

最后大剑回旋对每名锁定敌人分别造成「前五段在该敌人身上已造成的总伤害×70%」，四舍五入到整数，包括这些攻击引发的即时元素反应和在终结前已结算的关联持续伤害。打空的近战或弹丸不计伤害。只统计当前大招来源，普通射击、之前大招、其他来源不计入。敌方护盾、实际扣血和前段伤害加成先结算，终结系数不再重复叠加增伤、减伤或暴露倍率；终击仍受当前无敌、剩余护盾和剩余生命上限约束。最后一刀没有元素附着，因此不另外触发一遍反应。终击之后才发生的弹丸碰撞或持续伤害保持各自效果，不追溯放大终击。

实机例：烬灯两枪接霜弦一枪，前两刀20、三枪30、熔解20，合计70，终击49。两种持有槽均可作为起手武器，释放时锁定本次配装。

成长修正：所有前段均获得等级和锋芒、枪斗专精增伤。三次武器攻击共用普通攻击的暴击及单次强化逻辑；溅射和跳电也获得对应伤害加成。大招反应获得等级×锋芒×枪斗专精×元素亲和，灼烧在创建时保存同一成长倍率，敌方时钟恢复后按原时间跳伤。没有伤害的控制反应不凭空增加伤害。元素反应不会复制触发枪击的暴击倍率。

升级三选一新增紫鸢「巨刃专精」，每级+15%，上限3级（+45%）；覆盖连招前三次巨刃、大招起手两刀及各场合实际使用缄锋的挥斩。达到上限退出候选。末刀不再额外乘巨刃倍率，保持总账×70%。Lv.12／锋芒4／枪斗专精3／元素亲和3的实机例：烬灯单发10→18，热裂20→47；再加巨刃3，起手刀击为33、22；暴击倍率2时烬灯单发36。以上均经过最终取整，实机报告为 artifacts/ultimate-growth-report.json。

大招不消耗普通武器冷却、第三枪自动换为副武器，不触发普通连招符印末枪效果。锁定目标死亡后不攻击新刷出的敌人。新波次刷新计时在演出中暂停。
