# 0.14 回廊地图与传送

按 M 或点击右上角「地图 · M」打开，M / Esc 关闭。查看地图时暂停游戏；如果从暂停菜单打开，关闭后仍保持暂停。剧情、升级和战利品选择期间先完成选择，再打开地图。独立防守关继续使用自身建造界面。

三个区域分别显示房间名称、类型、实际门路、当前位置、探索与清场状态。区域标签显示探索数量。未探索房间也显示位置，方便寻找任务，但不能传送。选中房间显示路线、交互提示，以及已到达房间尚未领取的宝箱和武器。

任务区逐项显示熔铸工坊三个阀门：齿轮中庭、冷却泵房、淬火车间。修复进度取自真实剧情记录，清场不等于修复；橙色轮盘表示待修复，已修复变为绿色勾选。点击任务会自动切换区域、选中对应房间。阀门位于房间上方中央，清场后靠近按 E 修复。

任务区同时列出当前区域未清理的六处普通战场，方便解除炉门封印。归途遗物房间另外显示「遗物待查看」或「遗物已查看」，不再把查看任务混同于清场。小地图增加房间类型标记、阀门状态、区域剩余战场数量和大地图入口。

传送免费，随探索自动解锁。起点必须清场且没有存活敌人或待出现敌人，目的地必须到达过并已清场。大招、连招、闪避、浮空与房间切换期间不能传送。按钮会说明不可传送的原因。角色落在目的地南侧安全入口，房间切换沿用正常进入逻辑，商店售出状态、首次休息、宝箱、金币、掉落、符印、成长和阀门进度均保留，不刷新奖励。

营地存档保持原格式，读档恢复探索与各阀门的准确状态；地图选中状态无需存储。

验证包含传送不能跳过未探索／未清场房间、战斗暂停与恢复、三个阀门定位及实际交互、重复营地访问不重复回血、掉落和库存保留、原营地存档恢复、35 个房间实际门路，以及浏览器 M / Esc、任务点击、传送和 640×360 布局。截图在 `artifacts/map-workshop.png` 与 `artifacts/map-region-3.png`。
