## 本轮完成

右键两枪改为自动必中：每次开火重新选最近存活敌人，沿统一伤害系统即时结算，显示锁定方向的短弹道；强化区域首击去重，普通左键保持鼠标瞄准。

降低敌人进攻压力：一只出手、其余半速绕行；延长攻击后恢复及观察，出生起手错开，精英第二击更慢并在玩家撤离时放弃追打。参数与节奏见[敌人进攻节奏](ENEMY-PACING.md)。

跑动24帧统一至各方向站立高度。右键改为五次独立输入逐段推进，段间窗口0.45秒、末尾0.12秒可预输入下一段；停止输入会结束，空中动作会安全落地。详见[手动连招规则](GUNFU-MANUAL.md)。

新增敌人受击硬直：直接轻击0.16秒、重击0.24秒；枪斗体术0.34秒、正踢0.45秒，终结射击0.30秒，精英取90%。命中中断挥击、突进和后续连击，释放攻击名额。重复命中取剩余时间与新时长的较大值，同次攻击不反复刷新，二次伤害不触发。硬直独立于元素控制保护，遵循敌人时间与暂停，受击姿态停顿并轻微震颤。

追加体型修正：攻击图集按待机比例重新缩放，普通射击与完整枪斗同步调整握持位置及腾空中心锚点。四方向对照见[体型对照](../artifacts/28-hero-scale-comparison.png)。

一次右键自动依次播放：拿枪下劈 → 上撩 → 横扫 → 正踢 → 后空翻 → 空中开枪 → 落地旋身 → 再开枪 → 收势。共2.34秒，空房间也可练习。空中和落地各一次武器出手，末枪自动换持副武器；整套只奖励一次枪斗势。

新增4张透明图128帧，每个动作有四方向专用姿态，后空翻含真实倒置帧，正踢明确伸腿，落地后完成旋身。武器握持按姿态帧校准，踢击枪位上移以免遮腿，闪光和弹丸共享枪口。空中高度与地面脚点分开，后撤32像素，影子缩小；结束保持最后动作朝向。正常待机呼吸、移动朝向、怪物受击范围仍保留。

短闪可以主动中断整套动作；地面受击也可打断，不延迟补射。腾空避开地面攻击但不算精准闪避；既有56像素短闪、精准时停、全近战敌人与五元素十反应保持。
