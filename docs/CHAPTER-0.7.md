# 最后一盏归途灯 · 第一章 0.7

2026-10-11更新：本文件保留0.7地图、剧情和初始节奏设计。当前0.8的成长、怪物护甲、Boss生命、元素反应、武器阶段和掉落规则以 [BALANCE-0.8.md](BALANCE-0.8.md) 为准，以下历史战斗数值不再用于当前版本。

本版将短关卡扩成三段冒险。35个连通房间包括18个普通战斗、3个精英、3个营地商店、3个剧情遗物事件、6个宝藏支路，以及入口和最终Boss房。过门保留房间状态，已清场房间不再发放击杀或清场经验。战斗页只保留像素HUD，详细数值在暂停页查看。

## 探索与剧情

十二年前的熔炉事故封住了灰烬城内城。现在旧钟重响，结晶向外蔓延，紫鸢循着师父留下的归途灯进入废城；余烬则追寻当年留下的守门人。同一地图提供两套角色台词。

外庭认识刻鸟灯罩，工坊发现事故后的维修记录，内城揭示声音与人影来自被冻结的最后一夜。灰冠骑士守了十二年，以为仍有人没回家。击败他、听完最后对话、领取战利箱，再到炉心前按E结束这一夜。结局保留地下外来结晶的后续线索。

每区六个普通房间全部清场，区域精英房才开门；门旁提示剩余数量。第二个区域还需修复 forge-3、forge-4、forge-5 三处泄压阀：清场后到房间上方的装置按E。第三、四、五工坊的装置固定显示，已修复变绿。小地图只显示当前区域及可见邻房，入口、营地、遗物和宝藏可回头访问。

剧情用可点击继续／跳过的短对话呈现，读剧情时暂停战斗。三个事件房的遗物需主动靠近按E，每个只奖励一次20经验和12金币，记录显示在暂停页。紫鸢的指枪与背身猫步休息动画、两种可爱待机和原有大招保持可用。

## 约半小时的节奏

普通房间2波，每波外庭4、工坊5、内城6只。外庭最后一间与工坊／内城第1、3、5间增加第三波，让后区多一些混编遭遇。精英房3波，最后一波一只720基础生命的区域炉卫；它也受深度倍率影响。Boss5400生命，无强制等待／无敌阶段。

目标是战斗加上行走、购物、升级和阅读剧情约28–32分钟；熟悉路线、跳过剧情和高输出配装可以更快。自动通关夹具启用无敌、近距离精准瞄准、逐段连招与满能量大招，并跳过对话、瞬移到门边，因此计时只用于比较战斗编排，不能等同真人生存通关时间。实际记录在 artifacts/chapter-timing-ember.json 和 chapter-timing-violet.json，仍需通过玩家试玩细调。

## 局内成长

等级1–12；升级经验为40 + 12×(当前等级−1)。普通击杀给4 + floor(深度/6)经验，区域精英40经验；普通首清16、精英首清36，修阀12。每级自动增加3最大生命、回复3生命、基础伤害倍率增加2个百分点，强化选择延后到清场或安全房间。

| 三选一强化 | 每次效果 | 次数上限 |
|---|---|---|
| 强健 | 最大生命+10，同时回复10 | 3 |
| 锋芒 | 攻击及元素反应伤害+6个百分点 | 4 |
| 枪斗专精 | 连招、大招及其元素反应伤害+8个百分点 | 3 |
| 巨刃专精（紫鸢） | 巨刃连招、大招起手两刀及缄锋挥斩伤害+15个百分点 | 3 |
| 元素亲和 | 元素反应伤害+8个百分点 | 3 |
| 坚韧 | 受到伤害降低4个百分点 | 3 |
| 轻盈 | 闪避冷却减0.04秒 | 3 |

可继续强化已选方向，达到上限的项目退出候选；每次最多3个不同选项。巨刃专精仅出现在紫鸢候选中，包含连招前3段、大招前2刀，以及正常攻击／连招／大招中的缄锋真实挥斩。所有强化都是局内成长，不改变动作播放速度。最高生命163、最高减伤12%，闪避冷却最低0.78秒。

攻击倍率为等级倍率×锋芒×枪斗专精（连招／大招）×巨刃专精（符合条件的刀击）；元素反应为基础反应伤害×等级倍率×锋芒×元素亲和×枪斗专精（来自连招／大招）。每项按等级叠加，不同增益相乘，最后四舍五入。反应、灼烧创建时计算一次增益，进入伤害系统后不再重复添加；武器原生溅射／跳电从基础数值结算一次武器增益。残响与复制伤害不再叠一遍已结算的倍率。大招末刀仍严格为同一目标前段已结算伤害（含关联反应）×70%，其成长由前段带入。

大招枪击与普通武器共用暴击、原生效果和单次武器强化逻辑，保留0.4倍单发基础预算；不改变普通射击冷却。旧v1营地存档自动补入巨刃等级0，其他成长和候选保留。暂停页分别显示通用增伤、枪斗／大招加成、元素亲和和巨刃加成。

中间深度线性插值。回头不会重复升数值；预警前摇不缩短。前半段只允许一只敌人占出手机会，深度10以后最多两只，两次起手至少错开0.55秒。最终房只有Boss占主要出手位。

## 陷阱与灰冠骑士

每区第2、第4普通房各两处地面机关。地刺／火裂有1秒预警，6秒周期内伤害期0.35秒，每个目标每周期最多命中一次；玩家基础伤害6，敌人18。紫晶地带只降低20%移动速度。清场后机关关闭。地面伤害不奖励精准闪避时停；敌人攻击仍可触发0.5秒窗口的2秒时停。时停与大招暂停陷阱、敌人动作和新一波登场，玩家正常行动。

灰冠骑士拥有32帧固定尺寸像素动作，黑铁铠甲、断冠、橙色炉心和熔刃。阶段按生命65%、30%进入裂铠／炉心燃尽。首段前摇1秒，回身段0.85秒，末0.22秒锁定方向。横斩范围140；下砸伴随160像素突进，地面预警显示整段通道和落点。第二阶段出现一次两只寄生体，每7秒生成一条有预警的火裂；第三阶段增加三段斩，完成整套后再休息。

普通受击不把Boss击飞、无限硬直或大招拖走；生命伤害与反应仍正常结算。韧性150／180／210，子弹削3、重击6、枪斗身体段12、终结枪8、大招每段14、反应14、精准闪避18；同一攻击ID不重复削韧。破韧后跪地2.5秒，受到伤害增加20%，之后重新充满韧性并留出起身时间。击败Boss会清理小怪、刀判定和危险地带，安静播放倒地与最后对话。

## 营地存档

每处营地首次进入回复25生命，库存各自独立。营地内每2秒及交易／选择后写入本机当前浏览器的存档；重新打开游戏可点“继续上次旅程”，恢复角色、两把武器、生命、等级、未选强化、金币、已买库存、已清房间、遗物与修阀进度。进行中的营地对话从本段第一句恢复，可跳过。

战斗途中退出会回到上次营地，不保存半场战斗；死亡、完成结局或点击重新启程清除当前局存档。另行保留的启程配装偏好不受影响。禁用本地存储仍可正常游玩，只是不出现继续入口。存档限定当前版本拓扑并校验数值，损坏数据不加载。
