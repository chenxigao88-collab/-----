# 灰烬回廊 0.3：枪斗术

> 本文为0.3历史规则。用户重新指定完整动作顺序后，右键与动画已改为[六式枪斗0.4](GUNFU-0.4.md)：一次按键完成下劈、上撩、横扫、踢翻空中射击、落地旋身射击和收势；不再采用本文的短动作衔接。短闪、精准时停、全近战敌人和元素基础规则保留。

主攻制造机会，通过贴身打击、短闪调整位置或精准闪避进入连招；有效衔接自动拔出副武器终结。玩家仍用鼠标决定攻击方向，终结后保持新武器。Q只负责主动调整换持，射击次数与元素反应本身不触发自动切换。

## 操作与三条连招

| 操作 | 行为 |
|---|---|
| 左键 | 当前武器普通攻击，支持按住 |
| 右键 | 按当前机会衔接枪斗连招 |
| Space | 有输入时按移动方向短闪；无输入时向瞄准反方向短撤 |
| Q | 手动换持，不重置武器冷却，不消耗枪斗势 |
| WASD、鼠标 | 移动、瞄准 |

| 连招 | 触发与窗口 | 结果 |
|---|---|---|
| 压身连击 | 主攻命中后1秒内，贴近并右键体术；有效近身范围约52像素 | 体术命中后拔副武器终结；挥空不切枪 |
| 滑步交叉 | 主攻命中后短闪调整位置；落地后0.45秒内右键，附近约160像素内有有效目标 | 拔副武器追击 |
| 破绽反击 | 避过真实攻击的精准闪避后0.8秒内右键，附近约160像素内有有效目标 | 在时停机会中拔副武器反击 |

没有命中机会的普通逃跑闪避不产生滑步连招，也不会自动切枪。优先处理精准闪避反击窗口，其次滑步交叉，最后近身打击。满足接续条件后，终结仍沿鼠标方向执行；目标在附近不意味着必定命中。

三条连招共用1.2秒接续间隔；正常终结采用约0.25秒分段动作，按副武器一次基础攻击的75%伤害计算，近身体术基础伤害8且不附加元素。连携攻击计入武器攻击预算，冷却不因自动切换而重置，不能凭切换跳过恢复动作。

贴身体术在0.105秒接触，命中姿态保留至0.155秒后进入0.25秒拔枪动作；拔枪第0.105秒出手。滑步交叉和反击动作各0.30秒，出手时点同为第0.105秒。强化终结沿用原技能形态，伤害也受75%终结倍率约束；既有元素反应基础伤害保持。

## 枪斗势与六种终结

有效完成连招积累20枪斗势，成功精准闪避积累20，最多100。满势强化下一次有效终结；Q手动换持与普通命中不消费或充填该资源。强化终结使用对应武器既有技能形态，受该武器的强化终结冷却限制，不额外赠送一整次普通攻击与一整次技能伤害。

| 武器 | 元素 | 终结风格 | 强化终结 |
|---|---|---|---|
| 灰针 | 雷 | 快速精准点射 | 凝针强化单发 |
| 砾钟 | 岩 | 近距收束散弹 | 压钟收束弹道 |
| 缄锋 | 风 | 拔刀横斩 | 回锋旋斩聚怪 |
| 霜弦 | 霜 | 冰晶贯穿 | 霜锁强化减速 |
| 烬灯 | 炎 | 火球终结 | 留烬封锁路线 |
| 鸣枝 | 雷 | 电弧连接 | 落雷延迟区域打击 |

元素直接命中仍附加5秒印记，不同元素命中触发对应反应。近身体术、反应伤害与持续伤害不推进主攻机会，不回充连招资源，不触发时停。反应间隔、范围去重、硬控保护等0.2规则保持。

例如：烬灯主攻附火 → 横向短闪躲开扑击 → 右键拔出霜弦终结 → 热裂 → 保持霜弦，寻找下一次机会。

## 短闪与敌方时停

| 参数 | 数值 |
|---|---:|
| 闪避距离 | 约56像素 |
| 闪避动作时间 | 0.14秒 |
| 无敌窗口 | 前0.11秒 |
| 精准闪避判定 | 前0.07秒 |
| 闪避冷却 | 0.9秒 |
| 敌方时停 | 0.30秒 |
| 恢复过渡 | 0.12秒 |
| 时停奖励间隔 | 2秒 |

只有原本会命中的真实攻击在精准窗口内被避过，才给予时停奖励；对空气短闪不奖励。时停中玩家仍可移动、瞄准和反击，敌方移动、攻击动作与伤害判定暂停。一次闪避最多奖励一次，时停不叠加、不刷新，被冻结的攻击不重复提供奖励。恢复后保留敌人尚未完成的动作，并给玩家短暂的防立即受击保护。

敌方异常状态和持续伤害随敌方时钟暂停，玩家武器冷却与连招窗口继续推进；游戏暂停时所有这些时钟均停止。恢复过渡开始时给予玩家0.08秒保护。敌方褪色和边框提示时停，HUD仅显示一处时停信息。

## 全近战敌人

三波保留2／4／5只，第三波含一只强化炉眼。当前角色内部类别标识保留兼容性，行为改为近战。

| 怪物 | HP | 移动速度 | 攻击 |
|---|---:|---:|---|
| 炭爪 | 64 | 160 | 约0.42秒预警后近身横扫，基础伤害9 |
| 线棺 | 52 | 185 | 侧翼接近，约0.55秒预警后扑进100–130像素，基础伤害10 |
| 炉眼 | 112 | 100 | 约0.75秒明显预警后重型砸击，基础伤害14 |
| 强化炉眼 | 240 | 重型行为 | 两段砸击，首次闪避后仍需注意第二段 |

扑击锁定后不持续追踪玩家；横扫和砸击在出手前短暂锁定朝向。单次攻击的同一伤害判定不会连续命中同一对象。同一时刻最多两只怪物发起近身进攻，其余尝试侧翼接近。

## 角色表现与界面

待机保持固定站姿的轻微上下呼吸；移动身体朝向仍由运动方向决定，武器随鼠标瞄准。枪斗使用分段的贴身打击、滑步、拔枪／拔刀与反击表现，伤害发生时点与动作阶段对应，脚底位置与身体受击范围不随表现位移漂移。

本轮新增64帧四方向动作并接入两张透明图集；滑步残影使用实际动作阶段，普通射击使用架枪与后坐帧。原图和实际提示词见[GUNFU_ART.md](GUNFU_ART.md)。

短闪残影使用实际身体朝向，终结突出副武器拔出与出手，元素反应在命中处落点。精准闪避配合敌方时停与明显提示，HUD显示当前衔接机会、剩余窗口、枪斗势与连招完成次数。配装界面展示两把武器的反应和两个方向的强化终结。

## 验证与后续调整

本文件记录0.3实现约定，实际验证结果以最终更新的测试与浏览器报告为准。重点检查挥空不切枪、三种窗口边界、自动切换不重置冷却、时停暂停敌方伤害、时停恢复后不会立即补打一击、完美闪避不能形成永久时停，以及死亡／胜利／重开后的状态清理。

所有15种双武器配装仍需结合人工试玩调整收益。全近战阵容提高了减速、禁足和聚怪价值，首版保留元素基础数值；必要时优先调整控制覆盖和敌人出手节奏，再调整伤害。站立射击应能完成基础战斗，主动枪斗更有收益，持续后退不能应对所有敌人。
