# 探索与奖励美术

使用内置 imagegen 生成透明图集，原图保存在 public/art/adventure-atlas-v1.png，索引位于 public/art/adventure-atlas-v1.json。原始像素与透明通道保持不变；索引脚本只生成帧矩形、固定比例与脚点元数据。

图集包含铜扣宝箱开箱8帧、晶封宝箱开箱8帧、行商待机及招手8帧。两个宝箱分别使用固定0.22显示比例，行商使用固定0.24比例；每帧按底部结构校准脚点，开启时只改变箱盖姿态。浏览器采用最近邻显示。

GUI边框、符印图标、金币旋转、场景门与障碍物由项目内像素绘制程序制作，使用固定网格与离散色阶。
