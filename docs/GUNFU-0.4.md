# 六式枪斗 0.4

以下保留原自动演武的动作参数。当前输入已改为[五次右键逐段连招](GUNFU-MANUAL.md)，不再一次右键自动执行完整动作。

用户明确要求的动作顺序替代0.3“体术接拔枪”的短动作。**一次右键完整播放**：拿枪下劈 → 上撩 → 横扫 → 正踢后空翻并空中开枪 → 落地旋身再开枪 → 收势结束。空房间与挥空同样播放完整动作，不再要求先命中或接近目标才能看到后续部分。

## 阶段与时点

| 内部阶段 | 时长 | 出手或表现 |
| --- | ---: | --- |
| 拿枪下劈 | 0.26秒 | 第0.13秒，3点物理伤害，54范围 |
| 上撩 | 0.24秒 | 第0.12秒，3点物理伤害，54范围 |
| 横扫 | 0.28秒 | 第0.14秒，4点物理伤害，58范围，最多3个目标 |
| 正踢 | 0.24秒 | 第0.12秒，6点物理伤害，60范围，较强击退 |
| 后空翻 | 0.36秒 | 仰身、团身、头下脚上倒置、展开；向后实际移动32像素 |
| 空中射击 | 0.24秒 | 第0.09秒，当前武器开火一次 |
| 落地旋身 | 0.32秒 | 从腾空落下、屈膝、完整转身、重新架枪 |
| 落地开枪 | 0.24秒 | 第0.06秒，拔出副武器开火一次并保持换持 |
| 收势 | 0.16秒 | 降下持枪手、回到站姿 |

完整动作2.34秒，结束后恢复0.45秒再接受下一次右键。四次近身接触均是物理伤害，不附元素，单阶段不会重复命中同一目标。空中、落地各一次武器出手；散弹的一次开火仍可发射六颗弹丸。两次射击各取对应武器基础伤害的37.5%，共享此前75%的终结预算；既有元素反应基础数值保持。

缄锋配装在枪斗中使用副手风弹手枪，仍按缄锋的元素和伤害预算结算；左键保持正常刀斩。满势只可强化落地出手，受副武器独立技能冷却约束；已有区域技能仍保留形态并显示开火反馈。

## 操作和中断

鼠标继续控制两次射击的方向，不自动追踪目标。近身动作按该阶段开始的方向出手，下一阶段可重新转向。地面演武允许较慢移动；后空翻实际后撤，空中不叠加自由移动。短闪可以主动中断整套动作；地面受击、死亡、重开和调试换武器也会清理动作，不会在稍后补发未完成的射击。

腾空超过8逻辑像素时避开地面攻击，落地恢复受击；腾空免伤不触发精准闪避奖励。56像素短闪、真正精准闪避触发0.30秒敌方时停、0.12秒恢复、2秒奖励间隔保持0.3规则。完美闪避和带命中机会短闪仍提供反击／滑步入口，但播放的都是这一整套动作，而非不同的短姿态。

整套两枪共享gunfuSequence：命中任一枪可获得20枪斗势、统计一次命中连招，不因第二枪、散弹多弹、跳电或区域多目标重复奖励。精准闪避仍另奖励20。普通左键与Q不积累或消费枪斗势；自动换枪发生于落地射击成功出手，无敌人也可换持。容量不足不会吞满势或错误切枪。

## 动画与实现

新增4张透明图、128个四方向完整姿态。下劈和上撩有不同的手臂高度，横扫有扭腰，正踢有明显伸腿，后空翻有真正倒置帧。落地旋身通过四向姿态轮换完成一圈，枪与身体同步转动。动作握持高度按当前姿态帧校准，枪口闪光和弹丸共用握持点；腾空以地面脚点与空中高度分开绘制，地面影子随高度缩小。收势后保留最后的动作朝向，正常WASD移动仍按运动方向。

时长／接触点／伤害及握持参数在src/data/gunfu.ts；推进和中断由GunfuSystem负责；Actor.action保存姿态／高度／腾空状态；SpriteRenderer只负责显示。原图保持不变，索引器按透明连通轮廓识别每帧，避免生成网格小偏差裁掉脚尖或踢出的腿。

## 验证边界

200项逻辑测试通过，包含六式顺序、两次射击时点、四次接触、资源整套去重、空中免伤与落地、中断不补射、30/60/144Hz一致性、暂停和全部15种配装无敌夹具三波流程。浏览器实际右键输入与四方向动作检查通过；本次录制是实际游戏渲染。配装生存难度和2.34秒动作的实际手感仍需人工试玩，未声称完成全面数值平衡。
