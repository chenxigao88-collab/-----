# 手动枪斗连招

开火时自动瞄准：每个武器攻击段重新选择距玩家地面位置最近的存活敌人，同距离按实体编号稳定选择。身体与持枪方向跟随目标，发射装备武器自己的真实弹丸，保留原有数量、速度、散布、射程、穿透、反弹及原生效果；不画枪口到敌人的必中光线。伤害在弹丸碰撞时才结算，目标移动、散弹射程不足、遮挡或弹体容量已满均可能导致落空。第一枪击杀后，下一枪重新选敌。无敌人时沿鼠标方向空放，普通左键仍由鼠标手动瞄准。元素、受击硬直及同一连招共享一次枪斗势奖励沿用原规则。

散弹保持六枚散射弹丸，逐枚碰撞判定。强化落雷和留烬遵循武器原有区域技能、落点限制与延迟，没有额外提前必中首击。装备缄锋时，对应武器段使用挥剑动作和 MeleeSystem，遵循72像素范围、1.92弧度扇区、0.07秒起手、0.1秒判定、0.18秒收势；满势回锋仍用78像素旋斩技能范围。余烬使用横扫姿势，紫鸢使用巨刃回旋姿势，不持替代手枪。超出近战范围或隔着障碍物不会伤害敌人。第三段体术原有范围及击飞保持独立。

2026-10-05：替代0.4的一键自动演武。需要五次独立右键：①下劈 ②上撩 ③横扫 ④正踢、后空翻、空中射击 ⑤落地旋身、副武器射击、收势。后空翻、射击与收势属于对应一段内的连续动作。

段间0.45秒可再按一次继续；不输入则结束。前三段与空中射击末尾0.12秒允许预输入一次下一段，最多缓存一段，不能提前存完整连招。按住右键只执行第一段。结束或中断后重新按键从下劈开始。

第四段结束即安全落地，不等待输入而持续悬空。落地耗时0.08秒，在衔接窗口内；若第五次输入较晚，旋身从落地姿态开始，不再次抬升。只有执行第五段并成功射击才换持副武器。闪避、受击、暂停、武器替换沿用原有生命周期规则。

等待衔接时恢复正常移动；腾空落地期间保持移动锁定。体术受击硬直仍可衔接连续命中，但等待过久会给敌人恢复反击的机会。伤害、元素反应、两枪共享奖励与武器冷却保持0.4规则。
