# 0.9 · 射击机制与爽快战斗

2026-10-11。24把武器及前／中／后期掉落节奏保持，围绕九个武器族重做射击体验。本文覆盖0.8武器机制与怪物血量、数量的相关描述；人物强化、十反应公式、地图、Q独立3秒与营地存档沿用。

## 操作

蓄力枪按住左键积累，松开提前发射；蓄满自动发射，继续按住会在普攻冷却结束后再次蓄力。蓄力不降低移动速度。霜弦0.65秒、重弩0.75秒、烬灯0.8秒，直接显示蓄晶数量或蓄力条。换枪、闪避、受击、暂停及过门取消未发射的蓄力，不补射；普通攻击、技能与Q冷却不会被取消动作或换装刷新。

**余烬与紫鸢的右键连招使用满蓄力弹体**，不等待左键蓄力，不延长动作。满势烬灯终结也发射满蓄火球，保持真实飞行和碰撞。紫鸢大招的三次武器出手同样使用满蓄力；其末刀仍按前段实际伤害的70%结算。原有连招0.8／0.65倍、大招0.8倍作用于满蓄弹体一次。Q限制继续只作用于手动换持。

## 九种武器体验

| 武器族 | 操作和机制 | 弹体表现与进阶 |
|---|---|---|
| 灰针 | 持续射击1.1秒逐渐达到1.85倍攻速；松开重置 | 高速长针与细尾迹；进阶保留穿透、破甲，取消雷织版附带的弹射和跳电，专注持续压制 |
| 砾钟 | 近距散弹，每弹真实碰撞 | 旋转岩屑与扇形散布；后期七弹、穿透与收束，重枪口闪光 |
| 疾风连铳 | 三发分别在0／0.065／0.13秒出膛 | 三枚风刃依次飞行；普通连发可随瞄准转向，中期第三发140%，后期170%；后期三发全中同敌后追加一枚追踪风弹 |
| 霜弦 | 蓄力决定数量；不足45%一枚，达到45%三枚，满蓄五枚，后期满蓄七枚 | 菱形冰晶围绕手部聚集，释放时扇形展开；每晶基础伤害26／42／64，充能不同时提高单晶伤害 |
| 烬灯 | 蓄力只扩大爆炸范围，保持单枚火球 | 前／中／后期直击24／39／58；爆炸半径36→96／48→120／60→148。邻敌爆炸伤害为直击快照的65%，不再次附着元素。中后期留火区1.5秒，后期再发生一次延迟爆炸 |
| 鸣枝 | 按住持续追踪放电，每秒7.5个脉冲；9次连续射击达到过热，停火0.65秒 | 折线电弧及连接敌群的跳电；单脉冲8／13／20，跳电6／11／20。显示热量条，松手与停火消热，独立落雷技能保持原伤害预算 |
| 镇岩重弩 | 蓄力只提高单发伤害，从100%连续升至220%，始终一根重矢 | 厚箭头、长矢身、金色尾迹和重后坐力；83／125基础伤害，满蓄182.6／275，继承原有穿透和35%／65%破甲 |
| 缄锋 | 普通刀尖命中（距离≥刀长65%）每次出手积一层，三层后下一刀追加剑气 | 原生刀弧加月牙剑气；剑气85%伤害、穿透两敌，近距离命中、反应和连招不刷剑势 |
| 回风环刃 | 抛出后自动返回；玩家移动改变回程路线 | 大型旋转环刃与弧形枪口风纹；中／后期飞出240／300距离，去程及回程每敌各命中一次。碰到障碍提前返回，返回途中遇墙消失，不穿墙追击 |

爆炸弹在击中敌人、墙体或射程终点时结算一次；直接命中的敌人不额外吃同一爆炸邻伤。三发连射共享反应去重和一次性武器奖励，第三发强化不会再触发一份待用爆炸。追击、剑气、火区和延迟爆炸继承适用成长一次，并保留护甲结算，不递归产生新反应。

所有弹体由Canvas直接绘制专属形状、尾迹和枪口闪光，并使用不同合成音色。没有新增武器贴图；沿用原有手持图，差异主要发生在射击、飞行、命中与声音。浏览器验证检查视觉和逻辑，音量、音色舒适度及整体爽感仍需玩家实际体验。

## 怪物的轻量调整

冒险中普通战斗每波从4／5／6只改为5／6／7只，精英终波随从从4增加到5。普通怪与精英生命在原深度倍率之上乘1.15，护甲、攻击力、移速与出手名额保持0.8规则；Boss继续独立12000生命、18护甲。非冒险试炼保持原血量与编排。

同一代表配装的灰针族实际伤害仍为14／43／103；同期炭爪生命由64／114／186升为74／131／213，击杀枪数现在为6／4／3。热裂仍为46／156／529。增加的是承伤空间与目标密度，角色成长收益仍保留，未普遍提升敌人攻击力。

每波人数达到七只，存档解析同步接受七只，同时继续接受旧版较少人数的房间布局。新增蓄力、热量和剑势为临时战斗状态，过门重置；营地继续保留武器、人物成长和原有冷却。旧武器ID和保存格式兼容。
