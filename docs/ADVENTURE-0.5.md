# 0.5 箱庭探索与动作构筑

2026-10-05，已实现并接入正式页面。

## 冒险循环

入口按E启程，靠近门按E进入相邻房间；战斗时封门，清场开门。地图有九个房间，包含三个普通战斗房、两个秘藏室、商店、入口、精英厅和炉心。普通房一至两波，守关使用现有强化炉眼和独立阵容。

连接关系见EXPLORATION-AND-REWARDS-DESIGN.md。侧库支路能绕过落灰回廊；封存秘室经转角连接铸造厅南门。回头不会刷新敌人、宝箱、掉落武器或商店库存。障碍物在每局生成镜像变体，普通敌人组合和出生顺序有小幅变化，本局地图保持不变。镜像只作用于障碍，门与地图方向固定。

跨房间保留生命、枪斗势、符印和剩余冷却。场景内弹丸、临时区域和残响在过门时清理，防止攻击进入安全房。门切换短暂淡入；交互只能在连招结束或主动取消后进行。死亡或重新启程重置本次冒险，浏览器保存的行前角色、配装继续沿用；刷新没有局内续玩存档。

## GUI与素材

战斗页保留像素头像血条、金币、小地图、短闪恢复、五颗枪斗势晶石、双武器格和最多三枚符印图标。连段节点只在动作期间出现，余烬五个输入节点，紫鸢六个。说明、物品效果和统计进入暂停或奖励面板；调试只保留F2。HUD使用固定960×540画布和像素绘制，与场景同步缩放。

图集包含两种宝箱各8帧及行商8帧，使用透明PNG和固定脚点。金币有8帧旋转。来源与实际生成提示词见ADVENTURE-ART.md。角色图集与既有连招动作顺序保持。

## 金币、宝箱与商店

开局20金币。普通敌人3金币、精英12金币；普通清场铜箱6金币，精英/守关铜箱14金币；秘藏箱另给18金币。金币短暂弹起，附近自动拾取；安全或清场后向玩家汇集。

每个战斗房首次有效末枪、首次元素反应、首次精准闪避各增加2金币清场奖励，最多6金币。复制伤害不计，重复动作不能反复赚取。场地熔炉被敌人的击退移动触发后，预告0.5秒再喷焰，对附近敌人10伤害、玩家6伤害，冷却3秒；机关伤害不触发元素或势。

铜箱无需选择；低于50生命时有40%机会额外回复8生命。晶封箱三选一，选择期间暂停；关闭后可重新选择原先内容，金币不重复发放。两个秘藏室各一箱。

商店安全，固定三货位：25金币回复25生命一次、45金币购买一枚符印、45金币购买一把武器。满血、余额不足或售罄时不能购买。武器预览与取消不扣费，确认替换A/B时扣费，旧武器落地可换回；槽位剩余冷却保留。掉落武器不能卖出，交换不会增殖掉落或金币。商店库存不刷新。

## 三槽动作构筑

共有10种符印，每名角色有8种角色适配符印，奖励池还会过滤对当前元素配装无效的符印。最多三枚，同名不叠加。首次宝箱分别提供追击、反击、元素方向各一枚；随后宝箱和商店优先提供已装备符印最多的方向，仍提供其他方向备选。满槽必须明确选择替换，取消不扣费或领取。

| 符印 | 对象 | 效果 |
| --- | --- | --- |
| 轻羽 | 紫鸢 | 回旋击飞滞空延长0.15秒 |
| 追猎 | 紫鸢 | 每套首次空中追射伤害提高20% |
| 轻落 | 余烬 | 有效旋身末枪后，短闪剩余冷却减少0.2秒 |
| 落火 | 余烬 | 空中枪命中后，本套末枪命中同一敌人伤害提高20% |
| 回锋 | 通用 | 精准闪避后2秒内起手命中，额外5点势，一次机会 |
| 护烬 | 通用 | 末枪命中获得8点护盾3秒，冷却8秒，不叠加 |
| 融流 | 通用 | 范围反应半径增加10%；单体反应伤害增加10%，硬控不延长 |
| 拢灰 | 通用 | 第三段横扫/回旋范围增加12，仍最多命中三个敌人 |
| 余辉 | 通用 | 反应后2秒内起手打中同一目标，额外5点势，消耗该次机会 |
| 终响 | 通用 | 末枪命中后0.16秒追加20%直接命中伤害残响 |

散弹残响合计同一次射击对首个目标的所有有效弹片伤害，不把武器原生跳电当成主枪命中。追加伤害不附元素、不累计势、不触发其他符印、硬直或额外连锁。各效果保留游戏现有整数伤害取整；不提高全局攻击倍率。护盾吸收有限伤害，不提供无敌。

## 验证

类型检查与正式构建通过；291项测试覆盖原有角色动作、手动连段、必中射击、元素特效、受击硬直、时停及新探索系统。两名角色以普通伤害、真实攻击和敌人AI完成整章；该通关夹具使用玩家无敌去除生存差异，不用于证明生存难度平衡。

新增浏览器检查从E交互走过九房、用实际奖励/商店按钮交易、检查图集加载和最终出口。正式版另用键盘移动及六次独立右键清理首个战斗房，检查金币汇集、重开和小窗口。验证报告在artifacts/adventure-browser-report.json和artifacts/adventure-production-report.json。
