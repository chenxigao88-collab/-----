# 战斗绘制素材（0.10）

使用内置 imagegen 生成透明 PNG，再用同一工具对图集间距、透明背景和反应动画作修订。原始生成图片保留，游戏读取 public/art 内的最终版本。

24 把武器分别使用独立图片区域：前期轻巧，中期强化构件，后期复杂轮廓。9 类弹体、枪口、蓄力、爆炸、命中碎片、普通刀光和右键连招刀光均由绘制好的图片呈现。10 类反应保留各自材料、8 帧时间序列与固定中心。

Canvas 仅负责裁取、缩放、旋转、透明度与图片合成。生命条、蓄力条、文字、调试和界面布局依然属于信息显示；不会用它们拼出武器和战斗特效。
