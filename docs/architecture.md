# 系统职责与生命周期（0.4 六式枪斗）

以下保留0.4基础架构记录。当前0.9拥有35房冒险、两角色逐段连招、三阶段Boss和24把分期武器，人物与反应数值见 [BALANCE-0.8.md](BALANCE-0.8.md)，当前射击、蓄力和怪物调整以 [WEAPONS-0.9.md](WEAPONS-0.9.md) 为准。`AttackContext`快照独立保存武器反应基数与破甲比例；`World`集中组合符印、人物成长、Boss状态和护甲；原生次生伤害继承成长一次，反应绕过护甲且不递归附着。`ProgressionSystem`统一定义强化常量，`AdventureSystem`保存已见武器及每房掉落事实，`WeaponStats`向HUD和比较面板提供相同人物成长口径。旧存档的可选新增字段保持兼容。

入口main只装配GameApp。GameApp持有唯一RAF、DOM输入管理器、共享美术、音频和当前World。每次重试先dispose旧World，创建新runId，清空输入、时间、攻击、枪斗势、连招机会、刷怪队列和局内事件。DOM订阅用AbortController，局内事件bus在结束释放。正式双武器配装保存在浏览器；F2临时调试替换不改变正式配装。

World协调一个固定步：时间域→玩家与两槽冷却→输入／短缓冲→枪斗动作→元素状态→AI→区域技能→弹体／近战判定→伤害事件→回收→导演与结果。不是每个角色自行访问浏览器输入。Renderer只读取世界，动画不决定伤害。

## 核心系统

- **Player**协调健康、hurtbox、击退、status与无敌；只有Health保存可写HP。WASD归一化，短滑步速度400、持续0.14秒，总距离56逻辑像素、冷却0.9秒。无方向输入时向瞄准反方向撤步，有方向时沿输入方向；最后一步把剩余滑步时间与普通走路时间分开，避免低帧率多走。滑步前0.11秒免伤，前0.07秒可精准闪避，身体朝向仍跟随实际移动。
- **EnemyBrain**复用Idle/Move/Attack/Recover/Stunned/Dead状态，三类敌人全部近战。炭爪（chaser，64HP）贴近扫击；炉眼（shooter，112HP）使用宽弧重击，强化体240HP、两段攻击；线棺（sniper，52HP）预警后沿锁定方向突刺116像素。旧kind标识用于素材和调试接口兼容，不代表仍使用枪械。最多一只敌人占用出手机会，其他敌人在附近绕行；有效期与强化第二段间隔仍占用机会。
- **DamageSystem**统一阵营、runId、死亡、去重、闪避和伤害。先记录本次攻击是否扣空HP，再发伤害事件；元素监听器同步补刀也只能产生一次死亡事实。玩家hurt无敌0.35秒；普通敌人受击不自动打断，元素硬控明确取消攻击。精准闪避只由MeleeSystem的实际碰撞调用允许奖励：接触时处于滑步完美窗口且确实靠滑步免伤、攻击有效、没有debug/hurt无敌、时间奖励可用。每次滑步和每个敌方AttackContext最多奖励一次。 六式动作高度超过8像素时避开地面攻击，但不算精准闪避；落地与中断即时结束腾空保护。
- **WeaponController**保存两槽及各自普攻／强化终结冷却。Q只调整当前换持，保留两槽冷却，不回充、不消费枪斗势，也不派发旧共鸣加成；切换动作锁0.16秒，独立手动切换冷却3秒。右键连招与大招自动换持不读取或刷新手动冷却；手动冷却使用玩家时间，过门及营地存档保留，旧存档缺省为0。近战或枪斗动作期间不能手动换持；闪避取消当前动作但保留武器冷却。
- **GunfuSystem**一次右键执行data/gunfu.ts中的9个内部阶段：下劈、上撩、横扫、踢击、后空翻、空中射击、落地旋身、落地射击、收势，总2.34秒。空房间和挥空也播放全套，不再依赖主攻命中。四个近身阶段各自碰撞，空中/落地各开火一次，落地成功出手自动换副武器并保持。完美闪避/滑步窗口只是整套枪舞的入口类型。分段推进保留跨阶段剩余时间，后空翻实际后撤32像素，结束恢复0.45秒；主动短闪/地面受击可以取消，不会补发后续子弹。
- **AttackSystem**每次武器出手创建攻击快照，散弹六颗共享一个AttackContext。gunfu=body表示3/3/4/6点无元素近身接触，gunfu=finisher表示空中或落地开火，gunfuSequence标识整套动作；两枪各使用武器基础伤害37.5%，共享此前75%终结预算。落地可消费满势采用既有技能形态。缄锋在枪斗中使用风弹副手手枪，普通左键仍刀斩。nativeDamageScale包含37.5%倍率，damageScale保留全局倍率，元素反应基础值不缩减；各槽冷却以max保留，不因自动换枪清零。
- **ProjectileSystem**相对位移的扫掠圆弹体对竖直胶囊碰撞，按墙/目标接触顺序结算；支持穿透、墙反弹、限定转向追踪、简单爆炸。TTL/距离/终止/局结束必回收，上限600；本版不引入池。胶囊由矩形与两端圆精确求最早接触，目标的前后脚点位移仍参与扫掠。
- **MeleeSystem**按windup/active/recover扫过角区间，每目标一次。玩家刀斩与敌人近战复用同一判定，分别推进player／enemy时间；敌方时间为0时不推进有效期，也不检测新的伤害接触。身体胶囊检测成立后，才允许DamageSystem判断精准闪避。
- **ResonanceSystem**保留类名，负责枪斗势。任一枪首次有效命中加20；gunfuSequence跨两枪、散弹和区域多目标去重，整套只奖励一次。精准闪避成功另加20，上限100。四次体术、普通左键、原生续接、反应和次生伤害不额外回充。满势在成功落地强化出手时消费，技能未就绪则保留；Q不消费。旧配对表不参与实战。
- **RoomDirector**持有本波aliveIds和出生预告，全部清空才推进；sandbox敌人不计数。最终同一步玩家死和敌人清空时死亡优先；胜利/死亡清所有攻击。
- **GameFeelManager**按preset协调顿帧、震动、闪白、粒子、飘字、环与音效。每个AttackContext只发一次主顿帧/震动；飘字按同攻击同目标短时间合并。
- **AssetManager/SpriteRenderer**加载透明PNG和裁剪metadata；四张gunfuRoutine图提供128帧四方向六式动作。Actor.action保存姿态、阶段时间、方向、lift和airborne；地面脚点不因腾空绘制而漂移，空中图以身体中心为锚点，影子随高度缩小。武器握持按同一帧的手部高度校准，弹丸、闪光与武器共用握持点；旋身阶段轮换四向姿态。普通移动保持运动朝向，普通武器独立跟鼠标；待机固定帧以1.6秒周期上下呼吸±1像素。索引器识别透明连通轮廓，保留原图。
- **HUD/Loadout/DebugPanel/Overlays**DOM呈现，UI只发GameCommand。HUD显示当前衔接机会、下一把武器、窗口和枪斗势；配装显示元素反应与两个方向的强化终结。Debug支持无敌、回血、重置、三种近战敌人、两槽、属性覆盖、参数滑条、碰撞/FPS/状态、弹体夹具、静音／屏幕提示开关。

## 受击范围与脚点

Actor.pos仍是脚点，Hurtbox.radius是地面移动／互相避让半径。Hurtbox.body单独保存身体胶囊的radius、offsetY、halfLength及可选offsetX；敌人参数在data/enemies.ts，参照实际精灵尺寸设定。子弹、近战、体术和爆炸共用该身体范围，追踪弹指向身体中心。玩家当前保持原来的脚点圆，作为零长度胶囊处理。碰撞诊断的绿色实线显示受击范围，敌人脚点虚线显示移动占地，不把独立武器算作可受击身体。

## 元素版本

0.2加入ElementalComponent、ElementSystem、AbilitySystem、ElementRenderer与Loadout。0.4保留五元素、十反应及去重／硬控保护，改变触发操作与时间域。元素副作用从damageApplied统一入口执行，次生伤害不递归，原生跳电复用主攻击去重集合。敌人的印记、反应冷却、减速、硬控、保护、熔痕和焰旋灼烧均推进enemy时间，冻结期保留剩余期限；玩家区域技能推进player时间，留烬／落雷仍能击中冻结敌人。区域first-touch去重使同一个目标只在首次有效接触时附着元素，后续伤害不重复建立连招机会或回充势。历史元素基础数值见[ELEMENTS-0.2](ELEMENTS-0.2.md)，当前玩法见[GUNFU-0.4](GUNFU-0.4.md)。

## 时间域

固定1/120秒。单帧接收最多0.1秒、最多12步，超额计入droppedTime。TimeManager每步返回以下时钟：

| 时钟 | 推进的内容 | 精准时停时 |
|---|---|---|
| active | 时停0.30秒、恢复0.12秒、奖励间隔2秒及全局顿帧期限 | 继续 |
| player | 玩家移动、两槽冷却、枪斗窗口、输入缓冲、区域技能与刷怪导演 | 继续；全局顿帧时为0 |
| enemy | AI、敌人移动／突刺、敌方近战／弹体夹具、敌人元素期限和灼烧 | 完全冻结为0，随后0.12秒由0线性恢复到正常速度 |
| presentation | 粒子、提示、屏幕反馈与可视效果 | 继续 |

精准闪避由DamageSystem发事实事件，World在TimeManager允许奖励时开启敌方冻结，并通知GunfuSystem建立反击窗口／增加枪斗势。冻结与恢复期间不能叠加或刷新冻结；从成功奖励开始按active时间等待2秒。freezeJustEnded是完整冻结转入渐恢复时的一步脉冲，World此时给予玩家0.08秒hurt保护。短全局顿帧仍是独立效果，最长0.07秒，会暂时停止玩家和敌人动作。精准时停采用完整冻结与渐恢复，不再使用旧0.3倍率慢动作。

暂停不调用World的局内时间推进，所有窗口和期限保持；恢复重置RAF时钟，不补算后台时间。死亡、胜利与dispose清除时间效果、攻击、区域、灼烧及连招机会。Renderer读取状态，不能通过动画时间提前结束冻结或控制。

## 有意简化

当前固定空房间，无寻路或导航网格。碰撞边界为x86..874、y92..450，与实际生成背景的内墙对齐。E印记位于(480,375)，出生点可直接开始。三波仍为2／4／5只敌人，末波含一只240HP强化炉眼。

美术使用独立房间背景，没有裁用户参考或概念板到游戏。敌人仍采用少量素材帧与范围预警表现近战阶段，并非完整每向攻击动画。没有全局可变单例、深继承或ECS框架。
